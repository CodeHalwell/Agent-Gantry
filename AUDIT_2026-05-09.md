### `openai` 2.36.0 — changes since 2.35.1

- **Realtime API v2** (`api: realtime 2`): Updated Realtime API surface. Not used by Gantry.
- **Manual API updates** (`api: manual updates`): Minor API surface additions. No changes to `chat.completions.create`, `responses.create`, tool schemas, or function calling.
- **No breaking changes** for Gantry's usage patterns.

Source: https://github.com/openai/openai-python/releases/tag/v2.36.0

### `mcp` 1.27.1 — changes since 1.27.0

Patch release (released 2026-05-08). No breaking changes. Gantry's MCP client and server code (`adapters/executors/mcp_client.py`, `servers/mcp_server.py`, `core/mcp_manager.py`) are unaffected.

Source: https://pypi.org/pypi/mcp/json

### `agent-framework` 1.3.0 — changes since 1.2.2

**New features (additive):**

- `ClassSkill` for declarative class-based skill definitions.
- `allowed_tools` parameter for OpenAI and Gemini tool-choice filtering — lets callers restrict which registered tools the agent may invoke on a given turn.
- Experimental session-mode, todo-list, and memory harness context providers.
- Information-flow control prompt injection defence.
- Function approval flow in Azure AI Foundry hosted agents.
- Python parity for `InvokeMcpTool` and `HttpRequestAction` in declarative workflows.
- New transitive dependencies: `agent-framework-hyperlight==1.0.0b260507`, `hyperlight-sandbox==0.4.0`, `hyperlight-sandbox-backend-wasm==0.4.0`, `hyperlight-sandbox-python-guest==0.4.0` (Hyperlight micro-VM sandbox for function execution).

**Breaking changes (neither affects Gantry):**

1. **Skills multi-source architecture restructuring** (PR #5584): Affects the experimental `SkillsProvider` / skills API. Gantry's integrations do not subclass or directly import `SkillsProvider`; it appears only in docstring examples in `agent_framework_provider.py`. If `SkillsProvider(skill_paths=...)` was being used alongside Gantry and the import path changed, update to the new multi-source form per the AF 1.3.0 migration notes.
2. **Removal of bespoke Foundry toolbox helpers** (PR #5671): Foundry toolbox helpers removed; MCP is now the standard pattern. Gantry does not use the removed helpers.

**Impact on Gantry integrations:** None. All AF symbols imported by Gantry — `Agent`, `AgentExecutor`, `WorkflowAgent`, `WorkflowBuilder`, `SequentialBuilder`, `HandoffBuilder`, `ConcurrentBuilder`, `ContextProvider`, `chat_middleware`, `FunctionMiddleware`, `ChatMiddlewareLayer`, `MiddlewareTermination`, `tool` (decorator) — remain stable in 1.3.0.

Source: https://github.com/microsoft/agent-framework/releases ; https://pypi.org/pypi/agent-framework/1.3.0/json
