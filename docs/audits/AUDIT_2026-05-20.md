### `agent-framework` 1.4.0 → 1.5.0 — breaking-change impact assessment

Release notes confirm **no breaking changes**. Changes affecting Gantry:

- **#5780** *(bug fix)*: Tools added by `ContextProvider.before_run` are now properly included in AF GitHub Copilot session creation. `GantryContextProvider.before_run()` calls `context.extend_tools(self._source_id, tools)` — previously those tools were missing from Copilot sessions; they now surface correctly with AF 1.5.0. No Gantry code change required.
- **#5623** *(enhancement)*: Enhanced intermediate-output handling in `WorkflowBuilder` / `SequentialBuilder` / `HandoffBuilder` orchestrations. `GantryToolBridge.build_workflow()`, `build_sequential_workflow()`, and `build_handoff_workflow()` all use these builders. The change is additive — existing workflow calls return more complete intermediate results without any API change.
- **Durabletask**: AF 1.5.0 sets `durabletask>=1.4.0` excluding 1.4.1–1.4.3. The lock file holds `durabletask 1.4.0`, which satisfies this constraint. `test_durable_worker_integration.py` exercises the cross-loop topology that mirrors `DurableAIAgentWorker`; no test changes required.

Source: https://github.com/microsoft/agent-framework/releases

### `anthropic` 0.103.0 → 0.103.1 — breaking-change impact assessment

Patch release; **no breaking changes**. Fix: `SessionToolRunner` no longer processes tool calls belonging to other runners. This is specific to CMA (Claude Managed Agents) multi-runner orchestration and does not affect Gantry's standard `client.messages.create()` usage.

Source: https://github.com/anthropics/anthropic-sdk-python/releases

### `google-adk` 1.34.0 → 2.0.0 — comment update only

`google-adk` reached **2.0.0** (released 2026-05-20). The floor in `pyproject.toml` remains at `1.14.1` because the langgraph conflict (`google-adk` requires `langgraph<0.4.8`; this extra requires `langgraph>=1.2.0`) is unchanged in 2.0.0. The comment was updated to reflect the new latest version; no install-behaviour change.

Source: https://pypi.org/pypi/google-adk/json
